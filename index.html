01

Gasolineras en Ruta

Full Stack · Personal Project

A web application that helps drivers find the cheapest petrol stations along their route. The user enters an origin and a destination — the system calculates the route and surfaces nearby stations with live prices, automatically identifying the most affordable option.

Architecture: Spring Boot REST backend with a PostGIS-enabled PostgreSQL database for geospatial queries. Frontend built with React and Leaflet for interactive map rendering. Price data is pulled daily from the official MITECO API (Spanish Ministry for Ecological Transition) with a one-download-per-day control. Stations are filtered within a 3 km radius of the route, with colour-coded markers by relative price and full station detail on click.
